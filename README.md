# 지연 · 포트폴리오

3D 장면 복원 연구와 소프트웨어 개발 경험을 정리한 포트폴리오입니다.

**사이트:** https://yeonnji.github.io

## 소개

3DGS 기반 장면 복원을 연구하고, 라이다 운용 소프트웨어와 영상 AI 관제 연동 기능을 개발했습니다.
문제가 생기면 처리 과정을 단계별로 살펴 원인을 찾고, 고친 뒤에는 목적에 맞는 기준으로 실제로 개선됐는지 확인합니다.

## 사이트 구성

- **홈:** 자기소개, 분야별 프로젝트 카드, 역량·기술, 이력, 연락처
- **상세 페이지:** 해결하려던 문제 → 담당 범위와 협업 → 주요 판단과 선택 이유 → 구현 과정 → 결과와 검증

Astro + MDX 정적 사이트이며 GitHub Actions로 GitHub Pages에 배포합니다. 정량 수치와 그림은 데이터 파일 한곳에서 관리하고 본문은 이를 불러와 표시합니다.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build
```
