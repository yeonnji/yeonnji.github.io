# 공개 범위와 라이선스

기본 원칙: 공개 가능 여부가 확인되지 않은 파일은 배포하지 않는다.

## 그림 공개 절차

1. `src/data/figures.yaml`에서 해당 그룹의 `status`를 `review` → `public`으로 바꾼다.
2. 그 그룹의 파일을 `src/assets/figures/review/…`에서 `src/assets/figures/public/…`(같은 하위 경로)로 옮긴다.
3. `npm run build` 후 `dist/`에 해당 이미지가 들어갔는지 확인한다.

`review/` 폴더는 `.gitignore`에 있어 저장소에 올라가지 않는다. GitHub Pages(무료)는 공개 저장소가 필요하므로, 커밋하는 순간 공개되는 것과 같기 때문이다.
